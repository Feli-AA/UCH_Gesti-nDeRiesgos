## Descripción

Trabajo práctico individual de gestión de riesgos utilizando SimpleRisk para analizar y documentar riesgos de una clínica privada.

El escenario contempla una organización con aproximadamente 120 empleados y 800 pacientes diarios, que utiliza sistemas digitales para gestionar historias clínicas, información de seguros y obras sociales y datos de facturación.

## Entorno

El entorno fue implementado utilizando:

- Linux Mint 22.3 Cinnamon en una máquina virtual VirtualBox.
- Docker.
- Docker Compose.
- SimpleRisk.
- MySQL.

SimpleRisk se ejecuta mediante Docker Compose para facilitar la reproducción del entorno.
