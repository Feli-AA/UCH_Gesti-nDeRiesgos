**Instrucciones de Instalación**
Para reproducir este entorno de SimpleRisk utilizando Docker Compose, siga estos pasos:
1. Navegar a la carpeta `entorno/`: `cd entorno`
2. Levantar el entorno: `docker compose up -d`
3. Acceder a `https://localhost/` desde el navegador web y aceptar la advertencia del certificado de seguridad local.
